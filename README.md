## 本地预览

这是无需构建、无需安装依赖的静态网站。在仓库目录运行：

```sh
python -m http.server 5175 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:5175/ 。

## 文件结构

- `index.html`：页面结构与内容。
- `style.css`：布局、字体与响应式样式。
- `palette.css`：三号方案的背景配色与最终视觉调整。
- `app.js`：产品案例弹窗。
- `assets/`：背景摄影及产品截图。

可将仓库根目录发布到支持静态 HTML 的托管服务，无需构建步骤。

## 内容维护

修改 `index.html` 更新介绍、作品、产品访问链接、文章及时间轴。修改 `app.js` 更新案例详情。修改 `palette.css` 调整最终版配色和局部样式。
